# FrontForge

FrontForge is a personal frontend engineering knowledge platform for learning, analyzing, building, organizing, and reusing modern UI patterns, components, animations, references, notes, and projects.

## Status

🚧 Currently under active development.

**Current version:** v0.0.0

## Planned Stack

- React
- Vite
- Tailwind CSS
- GSAP
- Node.js
- Express
- MongoDB
- Mongoose

## Development

FrontForge is being built incrementally from v0.0.0 toward a production-ready v1.0.0.
